# Activos web derivados

Los archivos de `fonts/` son copias de trabajo para la aplicación web, derivadas sin modificación de los archivos oficiales del mismo nombre en `../../assets/identidad/fuentes/`.

Los originales permanecen versionados en `assets/identidad/` y no se sirven directamente desde esa carpeta. Cualquier logo, imagen o conversión adicional debe registrar aquí su archivo fuente y su destino web.
