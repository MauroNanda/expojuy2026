- Las decisiones de producto y arquitectura se encuentran en [`docs/`](docs/).
- Las especificaciones funcionales vigentes se encuentran en el [store OpenSpec](https://github.com/MauroNanda/sdd-open-spec-expojuy2026/tree/main/openspec/specs).

## Arquitectura inicial

```text
Frontend: React + TypeScript + Vite
Publicación: GitHub Pages
Realidad aumentada: MindAR Image Tracking + A-Frame + Three.js
Backend proyectado: ASP.NET Core 10 + PostgreSQL
Contrato de API proyectado: OpenAPI
```
