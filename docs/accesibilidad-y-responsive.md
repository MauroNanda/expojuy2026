# Accesibilidad y responsive

## Requisitos mínimos

- Diseño mobile-first y adaptación a pantallas amplias.
- Navegación completa por teclado.
- Foco visible y orden de tabulación coherente.
- HTML semántico y jerarquía de encabezados consistente.
- Contraste suficiente entre texto, iconos y fondo.
- Textos alternativos para imágenes significativas.
- Formularios con etiquetas, mensajes de error comprensibles y validación accesible.
- Información esencial disponible sin depender de color, animación, cámara o sonido.
- Preferencia por reducir movimiento respetada cuando corresponda.

## Verificación

Cada funcionalidad debe verificarse en pantalla móvil, teclado y lector de pantalla o herramientas equivalentes antes de considerarse terminada.
