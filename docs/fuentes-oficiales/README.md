# Fuentes oficiales

Este directorio conserva los documentos oficiales que delimitan la propuesta y deben consultarse antes de tomar decisiones de alcance, contenidos o presentación.

| Archivo | Uso |
| --- | --- |
| `bases-y-condiciones.pdf` | Bases, requisitos, fechas y condiciones del concurso. |
| `consignas-tecnicas-del-desafio.pdf` | Consignas y criterios técnicos de la primera entrega. |
| `aclaracion-recursos-visuales-primera-etapa.md` | Autorización de la organización para usar recursos visuales de referencia e imágenes generadas con IA durante la primera etapa. |

Los archivos se conservan como originales de referencia. Las decisiones derivadas se registran en `docs/` o en el store OpenSpec; no se modifican los PDF.
