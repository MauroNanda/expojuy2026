# Alcance inicial

La entrega incluye una propuesta navegable publicada en GitHub Pages y la documentación que describe su experiencia, estructura y factibilidad técnica.

## Capacidades incluidas

- Inicio institucional.
- Información general del evento.
- Agenda de actividades.
- Directorio de expositores.
- Noticias.
- Sponsors.
- Contacto y preguntas frecuentes.
- Integración visual con redes sociales.
- Diseño responsive y accesible.
- Simulación visual inicial del recorrido de realidad aumentada, sin cámara ni reconocimiento de imágenes.
- Propuesta visual de mapa interactivo.

## Capacidades no implementadas

- API productiva.
- Base de datos productiva.
- Panel de administración.
- Compra o gestión real de entradas.
- Procesamiento de pagos.
- Integraciones externas definitivas.
- Mapa definitivo conectado a datos operativos.
- Realidad aumentada funcional basada en image tracking.

Los datos de demostración deben estar versionados y claramente diferenciados de contenido oficial.

Los recursos visuales de referencia y las imágenes generadas con IA están autorizados para esta etapa cuando se usen como contenido demostrativo trazable; se reemplazarán por activos institucionales cuando la organización los provea.
