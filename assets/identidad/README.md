# Identidad visual oficial

Este directorio conserva los recursos oficiales de identidad visual utilizados como fuente para las propuestas y la futura interfaz.

- `fuentes/` contiene los archivos tipográficos provistos.
- `logos/fuente/` contiene los archivos originales de logo en sus variantes y formatos disponibles.

Los originales no se modifican. Los recursos optimizados para la aplicación se crearán en el change que implemente la interfaz, conservarán la trazabilidad hacia esta fuente y respetarán las condiciones de uso aplicables.
